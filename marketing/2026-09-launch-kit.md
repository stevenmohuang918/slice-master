# 切图大师首月推广内容包

适用网站：<https://www.slicemaster.com.cn/>  
目标用户：UI/前端开发、产品设计师、独立开发者。  
产品边界：在浏览器本地从 UI 截图中发现图标与插图，用户校对后导出透明 PNG；不承诺识别所有文字、还原源设计文件，或上传图片至服务器。

## 30 天目标与观察方式

先以真实使用质量为先，不急于购买流量。每周查看：访问量、`upload_started`、`detection_completed`、三类导出事件，以及收藏/分享引导的打开次数。

第一轮可用目标：

- 100 次真实访问；
- 30 次上传；
- 上传到完成识别比例不低于 70%；
- 完成识别到至少一次导出比例不低于 35%。

若“上传高、导出低”，优先检查误识别、移动端预览和导出结果；若“访问低”，再加大内容分发。事件统计不包含图片、文件名、切图内容或用户身份。

## 三篇可发布内容

### 1. 从一张 UI 截图到可交付 PNG

**标题**：设计稿只有截图，前端怎样快速拿到可用图标？  
**开头**：设计交付不完整时，最耗时的往往不是写页面，而是逐个截取图标、去掉背景、反复核尺寸。切图大师把这一步放在浏览器里完成：上传截图、校对识别框、只导出真正需要的 PNG。  
**配图建议**：同一张 UI 截图 + 3 个识别框 + 透明 PNG 缩略图。  
**CTA**：打开切图大师，试着从你的一张 UI 截图里提取图标与插图。

### 2. 为什么截图切图经常切到文字？

**标题**：UI 自动切图的误区：文字不应该成为你的资产清单  
**开头**：页面截图里有大量标题、说明和按钮文案，但开发真正需要复用的通常是图标和插图。切图大师默认提供“忽略文字内容”，并保留手动框选、删除和精确尺寸调整，让输出清单回到开发资产本身。  
**配图建议**：开启/关闭“忽略文字内容”的对比图。  
**CTA**：用一张复杂页面截图验证一下，保留你需要的视觉元素即可。

### 3. 交付前的透明 PNG 检查清单

**标题**：交给前端前，UI 切图至少检查这 4 件事  
**开头**：透明背景、边缘留白、统一尺寸和命名规则，决定了切图会不会在页面里“看起来不对”。切图大师支持单张下载、批量导出和预览拼图，方便设计与开发一起确认。  
**检查清单**：透明背景是否正确；画布尺寸是否统一；不需要的文字是否排除；批量 ZIP 是否可直接解压。  
**CTA**：将检查清单和网站链接一起发给设计/开发协作群。

网站现有文章可用作长文承载页：`/articles/how-to-extract-icons/`、`/articles/design-handoff-assets/`、`/articles/png-svg-webp/`、`/articles/ui-screenshot-to-assets/`；英文读者使用对应的 `/en/articles/` 地址。

## 三条短视频脚本（20–30 秒）

### A. 一张截图，三个步骤

画面：展示一张 UI 截图。  
口播：`一张 UI 截图，图标怎么交给开发？打开切图大师，上传截图，校对自动识别的区域，最后只导出需要的透明 PNG。图片始终在浏览器本地处理。`  
结尾字幕：`让 UI 切图，如此简单。`

### B. 不要把文字也切出去

画面：先出现满是文字框选的失败示例，再开启“忽略文字内容”。  
口播：`自动切图不是框越多越好。页面里的标题和段落不是开发资产；保留图标和插图，再手动补一个框，交付会更干净。`  
结尾字幕：`只导出开发真正需要的切图。`

### C. 透明背景，单张或批量都能交付

画面：缩略图中的透明棋盘背景、单张下载、导出 ZIP。  
口播：`需要一张图就单独下载，需要一组图就多选导出。先看透明背景是否正确，再把 PNG 直接交给开发。`  
结尾字幕：`切图大师 · 本地 UI 资产提取。`

## 渠道与发布顺序

1. 先发布中文图文到公众号、知乎、小红书或技术社群，使用上方内容 1。
2. 两天后发布“误区”短视频，链接回文章和工具首页。
3. 一周后发布开发交付清单，并邀请用户带一张非敏感截图试用。
4. 英文版优先投放到 Product Hunt 上线准备页、Indie Hackers、X 和面向前端的 Discord/Reddit 社群；先遵守各社区的自荐规则。

不要在未获授权的第三方社区自动发帖。每次发布只用真实能力表述，不声称 AI 能还原源文件或保证所有设计图 100% 正确。
