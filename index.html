切图大师是什么？

切图大师是面向设计师与前端开发者的 UI 资产提取工具。上传设计截图后，它会优先识别独立的图标和插图；你可以校对结果、精确调整裁剪框，再导出开发可直接使用的透明 PNG。

识别对象
UI 图标、插图、按钮图形和其他独立视觉资产。
本地处理
图片和切片只在当前浏览器处理，不会上传到服务器。
开发交付
支持多选、单图下载与 ZIP 导出，便于直接交给开发使用。

常见问题

切图大师适合哪些设计图？

适合包含清晰图标、插图或控件图形的 UI 截图。对于文字、复杂照片背景或重叠元素，建议先校对自动识别结果，再通过拖动或数值精确调整。

导出的图片可以直接用于页面开发吗？

可以。导出的是透明背景 PNG，适合以图片资源方式接入 Web、App 或小程序。它不等同于可编辑的 SVG 矢量文件。

上传的设计图会被保存吗？

不会。图片识别、背景透明化和导出都在本地浏览器完成，刷新或关闭页面后不会保留在本站服务器。

What is Slice Master?

Slice Master is a UI asset extraction tool for designers and frontend developers. Upload a design screenshot, review detected icons and illustrations, fine-tune each crop, and export transparent PNG assets ready for implementation.

What it finds
UI icons, illustrations, button graphics, and other independent visual assets.
Local-first
Your image and slices are processed in the current browser, never uploaded to a server.
Developer-ready
Select multiple assets, download one image, or export a ZIP for development handoff.

Frequently asked questions

Which designs work best?

UI screenshots with clear icons, illustrations, and isolated graphics work best. Review the results, then drag or enter pixel values for precise crops.

Can the exported assets be used in development?

Yes. Exports are transparent PNG files for web, app, and mini-program projects. They are bitmap assets, not editable SVG vectors.

Is my design image stored?

No. Detection, background transparency, and export all happen locally in your browser. Closing or refreshing the page does not save the image to this site.
