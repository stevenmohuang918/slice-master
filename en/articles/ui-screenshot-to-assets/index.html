From screenshot to usable assets

Slice Master does not turn an entire design into a scattered pile of images. It helps you find independent icons and illustrations in a complete interface, then decide which of them are worth handing to developers.

What can the tool detect?

The tool uses pixel colour, connected regions, and element boundaries to look for independent visual elements in a screenshot. Icons and illustrations on light or solid backgrounds with clear spacing work particularly well. Complex photos, gradients, dense text, and overlapping elements are better reviewed or corrected manually.

From automatic detection to human confirmation

Automatic detection is a starting point, not the final delivery. Use the text filter to reduce titles, labels, and paragraphs, then adjust sensitivity and minimum size to control the candidate set. Keep genuine icons and illustrations, remove unrelated elements, and draw crop boxes on the source image for anything missing.

Treat results as a candidate list

The most effective workflow is not chasing perfect automation. Let the tool find most candidates, then spend a small amount of time applying visual and product judgement.

How exact crop boxes help development

Each crop box can be moved on the source image or resized from its sides and corners. Enter a width and height when a consistent size matters. For a family of same-specification icons, save a default box size and apply the current dimensions to selected slices to keep the output consistent.

Three checks before export

  1. Confirm that transparent backgrounds meet the design need and keep a standard canvas for fixed-size icons.
  2. Select only the elements developers will actually use; leave out text, containers, and decorative noise.
  3. Export by module or state and use clear names for a more efficient handoff.

Privacy and local processing

Slice Master processes screenshots, slices, and exports in the current browser. The source image is not uploaded to this site's server, which makes the tool suitable for unreleased designs and internal project screens. Refreshing the browser does clear the current work.
