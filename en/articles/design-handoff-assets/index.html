Which design elements should be exported?

Not everything in a design file should become an image. Give fixed visuals to the asset pipeline and changing content to code for a more resilient UI handoff.

One-sentence rule

If an element changes with data, language, state, or viewport size, let code own it. If it is fixed and detail-heavy, consider exporting it as an image.

Four types of elements to export first

ElementWhy export it?Handoff note
Brand and complex graphicsLogos, textures, hand-drawn illustrations, and 3D visuals are hard to reproduce reliably with CSS.Document ratio, background, and light/dark variants.
Fixed iconsThe appearance is stable and transparent edges or shadows need to be preserved.Use shared canvas and naming rules.
Campaign and business visualsBadges, posters, product images, and other media are content assets.Group by page, campaign, or state.
Reusable illustrations in screenshotsA finished screenshot may be the only clue when the source file is unavailable.Keep a human review step to avoid neighbouring copy.

Content that should usually remain code

Headings, body copy, prices, form fields, ordinary button labels, dividers, and standard rounded containers should normally be implemented with HTML, CSS, or components. They need to adapt to viewport, language length, data state, and accessible reading order.

Handoff checklist

  1. Does each asset have a clear purpose, page location, and state?
  2. Do icons in one family share canvas size, padding, and naming?
  3. Have editable labels, prices, or business data been mistakenly exported?
  4. Are display size, density, and stretching rules documented?
  5. Can a developer find the right file in 30 seconds without asking the designer?

Frequently asked questions

When should a design element become an image asset?

When it is fixed, detail-heavy, and does not change with data or language.

Should headings and button labels be exported as images?

Usually no. Keep them in code for responsive layout, search, accessibility, and maintenance.

What notes should accompany handoff images?

At least filename, purpose, state, canvas size, display size, and stretching rules.
